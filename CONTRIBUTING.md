# Contributing

This repository is built by directing Claude Code against `docs/spec.md`. Issues describing a spec gap, a broken link or an accessibility problem are welcome.

For a change: open an issue first. Pull requests need green CI and a test named with the requirement id it proves.

Set up: `npm ci`, then `npm run check`, `npm test`, `npm run build` and `npm run e2e`.
