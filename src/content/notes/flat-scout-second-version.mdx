## What happened

In mid October, the first run of the second version of flat scout, which ran on the Opus model and was search-only, fanned out to many subagents for <Fig row="E6">about 50 minutes</Fig>.<Ref id="E6" /> That run consumed the evening's usage allowance.<Ref id="E7" /> After that run I set all approvals to manual.<Ref id="E8" />

## Causes

1. The run was broad and long: many subagents for <Fig row="E6">about 50 minutes</Fig>.<Ref id="E6" /> The allowance was gone by the end of the evening.<Ref id="E7" /> I read the run's breadth and length as the reason.<Ref id="E6" /><Ref id="E7" />

## What changed

- I set all approvals to manual.<Ref id="E8" />
- The third version ran three times a day.<Ref id="E20" />
- It searched page one only.<Ref id="E21" />
- It used no subagents.<Ref id="E22" />
- It capped each run at <Fig row="E23">15 minutes</Fig> and <Fig row="E23">25 fetches</Fig>.<Ref id="E23" />
