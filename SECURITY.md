# Security policy

## Reporting a vulnerability

Use GitHub private vulnerability reporting: the "Report a vulnerability" button on the Security tab of this repository. Please do not open a public issue for a vulnerability.

## Scope

This is a static site with no forms, no cookies and no server code. A way to make it load a script or resource from another origin, or to store data in a reader's browser beyond the single theme choice, is a vulnerability.

## Supported versions

Only the latest published version of the site.
